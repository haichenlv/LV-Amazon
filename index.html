评级如何使用

它回答的是“一个准确产品要挤进当前首页，需要面对多少已经准确响应买家意图的产品”。

第一层：关键词语义。 同时满足成人目标人群、jelly材质与指定鞋型；只满足一项不算严格符合。

最终评级。 符合产品越多，上首页难度越高；视觉不符合仍可能给差异化产品留下入口。

Decision boundary

这份V2解决了什么，下一步还要验证什么

已经回答：增量需求成立，但五个核心词的首页供给密度已被重新核验。Fisherman的产品上首页难度相对最低；Mules、Mary Jane、Ballet与Kitten Heel均已进入高难度区间。
下一步要做：优先对Fisherman做完整竞品分析；其余词只在有明确视觉或产品升级假设时继续，并进一步拆解首屏广告/自然位、新品上架速度与准确产品的流量占位。
仍不在本阶段判断：利润、成本、CPC、最终款式和供应链可行性。

  • 候选词来源：Sif MCP market_get_asin_keyword_signals，8个头部及最新点击ASIN，每个最多返回300个流量词。
  • 曲线验证：Sif MCP market_get_keyword_history，US站、week粒度，对40个候选细分词逐词回查。
  • 流量竞争：Sif MCP market_get_keyword_competition继续用于读取Top3点击与转化集中度，但不再把Sif流量ASIN样本当成Amazon首页供给分母。
  • 首页供给：2026-07-27在Amazon US分别搜索5个核心细分词，以页面显示的首页1—48位为统一口径；结果会随时间、位置、广告与个性化变化。
  • 严格匹配定义：产品必须同时满足成人目标人群、jelly/PVC/TPU表达与指定核心鞋型；未能确认的产品不计入符合数量，因此数量为保守初筛值。
  • 视觉判断：结合首页主图与站外需求研究，判断产品是否表达对应场景和审美来源；视觉符合度是定性审核，不与严格语义数量混为一个精确百分比。
  • 难度阈值：严格符合≤12/48为低，13—24/48为中，≥25/48为高；这是供给密度下的相对上首页难度，不等于排名或销量承诺。
  • Top3集中度：点击/转化份额来自Sif竞争工具；份额低只说明购买与流量分散，必须与商品匹配证据结合，不能单独等同于供给空白。
  • 月度曲线：将同一自然月内的周度搜索量取算术平均，分别叠加2024、2025、2026；缺少非零返回值的月份留空。
  • “首次出现”：Sif返回的ABA周度搜索量序列中第一次出现非零值的年份。
  • “年度峰值”：该自然年内最高一周的ABA搜索量。2026为截至2026-07-12的年内数据。
  • 站外需求研究：综合秀场/产品页面、主流时尚媒体和公开名人穿着报道。人群画像为基于这些语境的分析推定，不等同于Amazon后台人口统计数据。
