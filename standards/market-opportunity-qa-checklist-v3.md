## D. 工具 2：站内有效同款判断

- [ ] 每个通过增量门槛的关键词均审核 Amazon US 首页前 48 位。（阻断项）
- [ ] 每个词先写清“有效同款判定规则”：产品必须同时满足该词的全部核心元素，而不是只命中其中一个词根。
- [ ] 标题/卖点语义、目标人群、产品结构、材质表达、主图视觉及真实使用场景均已核对。
- [ ] 例如 Kitten Heel：平底海滩 Flip-flop 不算；若产品确有 Kitten Heel 且同时满足 Jelly 视觉，Thong/Flip-flop 或 Mule/Slide 结构可以计入。
- [ ] 已区分前台 Results 和人工确认的有效同款。
- [ ] 每个词都有有效同款数量 x/48 和上首页难度结论。
- [ ] 无有效同款时直接进入高机会判断，不再堆砌无关竞品数据。
- [ ] 有有效同款时已核验 Clothing 大类 BSR 是否进入 #100 万、上架时间及主要变体配送方式。
- [ ] 配送方式和上架时间优先查看流量最高或流量词最多的两个主要变体。
- [ ] 已明确区分 FBM 新品、FBA 新品、FBA 老品和全部同款未进 #100 万。
- [ ] FBM/FBA 有效同款均提供可跳转 Amazon ASIN。（阻断项）
- [ ] 没有把“有效同款少”直接等同于“容易出单”，也没有把 #100 万门槛写成销量或利润。
- [ ] 没有把有效同款、BSR、时间或配送审核留给使用者。（阻断项）
